# Scholarship Admin Dashboard

A React-based dashboard for monitoring scholarship applications across Karnataka districts.

## Features

- District-wise analytics
- Institution-wise statistics
- Scholarship approval monitoring
- Responsive dashboard UI
- Search functionality

## Tech Stack

- React
- JavaScript
- Tailwind CSS
- Lucide React Icons

## Installation

```bash
npm install
npm start
```

## Future Enhancements

- Backend Integration
